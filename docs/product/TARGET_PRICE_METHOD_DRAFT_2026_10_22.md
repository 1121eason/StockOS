# NVIDIA 十二個月目標價方法草案

版本：TargetPricePolicyV1-draft1。日期：2026-10-22。狀態：方法待審核，尚未實作或發布正式目標價。範圍只有 NVDA；AI 不輸入價格計算。

交付定義：使用研究時點已知資料，推估十二個日曆月後的每股權益價值，稱為「十二個月模型目標價」。它是附帶假設的未來價值判斷，不保證市場在該日成交於此價格。既有研究日合理價值及財務公式保留原政策；新方法獨立版本化，不能替目前 DCF 卡片改名。

## 一、時間與資料契約

每份候選必須保存 `valuation_as_of`、`information_cutoff`、`target_date`、`target_timezone`、`forecast_run_id`、`research_snapshot_hash`、`policy_hash`、來源雜湊、情境假設與產出時間。

- 時區採 America/New_York。目標日是研究日期加十二個日曆月；閏年 2 月 29 日對應次年 2 月 28 日，保留原始時間規則。
- 折現採 ACT/365F，天數依日期差計算，不把四季硬當作研究日起剛好一年。目標日不是交易日仍保留該模型日期；事後價格驗證另標第一個不早於目標日的交易日收盤，不挪動當年的資訊截止時間。
- 只用 `available_at <= information_cutoff` 的資料。最新報價有自己的成交時間、取得時間與延遲狀態；報價更新不偷偷更新研究假設。
- 季度預測要轉成帶起迄日期與現金流時點的時程。跨越目標日的季度必須拆分；初版若使用按日均勻分配，須明列此近似、另測季末集中情境，不可把目標日前整季現金流再次留在目標日 EV。
- 現有年度 DCF 的折現分組不能直接當作這份日期化計算；兩者差異須可解釋。

## 二、主方法：目標日的營運價值，加上目標日淨現金，再除以目標日股數

主方法是日期化 FCFF DCF。營收、營業利益、稅率、OCF、capex 及既有 FCFF proxy 沿用已驗證的財務輸出；預測期間外的延伸規則要固定版本、保存假設。現有 proxy 對非現金項目、營運資金與非營運現金的近似限制，須繼續明示。

設研究日為 t0、目標日為 T、明確預測末日為 U：

```
EV(T) = Σ [FCFF(t) / (1 + WACC)^((t-T)/365)]，t > T
        + TV(U) / (1 + WACC)^((U-T)/365)

TV(U) = 穩定期下一年 FCFF / (WACC - g)
Equity(T) = EV(T) + 合格現金(T) + 其他非營運資產(T)
            - 有息負債(T) - 其他非普通股權益請求(T)
TargetPrice(T) = Equity(T) / 稀釋後期末普通股數(T)
```

必須滿足正有限 WACC、WACC > g、正穩定期現金流、正有限股數。其他非營運資產及權益請求只有核對存在、計量方法一致時才能使用；缺值不填零。

同一組日期化假設可做第二條獨立驗算：

```
EV(T) = EV(t0) × (1+WACC)^((T-t0)/365)
        - Σ [FCFF(t) × (1+WACC)^((T-t)/365)]，t0 < t <= T
```

這是現金流時點與折現一致性的驗算式，不能直接拿目前畫面的每股合理價乘上 WACC。期間現金分配、現金負債與股數都會改變；WACC 亦不是股價成長率。

FCFF 與 WACC 配對，FCFE 才與股權成本配對。現金與非營運資產另行處理，避免混入營運價值後重複相加。基礎估值原理參考 [Damodaran：DCF 與折現率一致性](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/problems/dcfprob.htm)。本節日期化目標日設計是 StockOS 的擬議方法，並非該來源已替本產品背書。

## 三、現金、債務、股息、回購與稀釋

目標日前建立獨立資本結構橋接表，每筆有來源、金額、日期、假設類型與計算項目：

```
Cash(T) = Cash(t0) + Σ(預測 OCF - capex)
          + 借款收入 - 償還本金 + 現金發股收入
          - 現金股息 - 回購支出 + 已核對的其他現金變動
Debt(T) = Debt(t0) + 新借款 - 償還本金 + 已核對的其他債務變動
Shares(T) = 研究日期末普通股數 + 期間淨新增／稀釋股數 - 回購註銷股數
```

OCF-capex 在此只用於現金滾動，不冒充 FCFF；利息、稅與 SBC 的處理沿用財務政策，逐項防止重複計算。受限制或營運不可分配現金需單獨標示，不一律當作可加回資產。

若最新資產負債表日期早於研究日，須先從該表日期逐期橋接到研究日，再橋接到目標日；同一期間不得計算兩次。不能把數月前的現金、債務或股數直接冒充研究日期末餘額。期間已公告事項用實際值，其餘用截至研究日已固定的預測並明示估計身分。

股數採估值用途的期末／目標日期股數，不能以 EPS 加權平均股數代替。拆股同時調整所有每股值、報價基準及股數，總權益價值不變。SBC 不再次扣成現金費用；未來 RSU、選擇權與稀釋須有明確處理，不能把 OCF 加回視為免費。

回購授權不等於已承諾回購。正式基準情境只能納入已核對的執行計畫或明示、已核准的假設；金額與買回價格要同時存在。不能用尚待計算的目標價直接反推買回股數形成隱性循環；初版固定使用研究截止日前可得的價格假設，另列敏感度。

股息在現金橋接扣除，目標價為目標日除息後權益價值。與現價的差距和「含期間股息的情境總報酬」分欄；股息不再加進目標價，也不能把未來股價差距標成保證報酬。缺少分配或稀釋資料時，只能輸出待核對候選。

## 四、Base／Bull／Bear 與缺值

三種情境都要有完整財務與資本結構時程，不能只對價格加減百分比。Base 使用已凍結基準預測；Bull／Bear 由具理由的營收、營業利潤率、現金轉換、再投資及風險假設組成。初版尚不給三情境機率，區間不宣稱為統計信賴區間。

情境參數數值仍待證據與方法審核，不在本草案憑空指定。WACC／g 的敏感度與經營情境分列，避免把所有最樂觀條件機械相乘。倍數估值如加入，只能作交叉檢查，需明確盈餘期間與當時可得倍數來源，不覆寫主方法。

以下任一未通過，`publishable=false`，保留上一個正式版本及原因：

1. 資料時間、幣別、拆股基準或來源核對失敗。
2. 日期化現金流不完整、部分期間規則缺失，或終值條件不合法。
3. 目標日現金、債務、股息、回購或稀釋假設未齊；不能用零補缺。
4. 現金滾動、股數或企業價值兩條路徑驗算不一致。
5. 任一主要情境依賴未核准 AI、未核准新政策，或未解同季財報更正。

負權益不能截成零或當成正常正目標價：標示特殊情境，暫停正式卡片發布並要求方法複核。

## 五、修訂歸因

每次新版本保留舊、新資訊截止時間及目標日。先在同一目標日比較，再單列「目標日期向後移動」的影響，避免把時間經過稱為基本面改善。

採固定順序的逐步重算：時間 → 營收 → 利潤／稅 → 現金轉換／再投資 → 折現率／終值 → 淨現金與分配 → 股數。每一步保存反事實輸入、價格差與來源；交互作用歸屬取決於順序，UI 要寫明此限制。各項合計必須與新舊目標價差一致，差額小於顯示精度，否則不發布歸因。

行情波動只改變「與最新可用價格的差距」，不列為模型目標價修訂原因。

## 六、實作前的驗收案例

| 案例 | 必須得到的結果 |
|---|---|
| 單期已知現金流與終值 | 直接重折現與向前橋接相等；T 前流量扣除一次 |
| 目標日在季度中間 | 分段天數完整無重疊；全年現金流守恆；改變分配時點有可解釋差異 |
| 股息支付 | 現金與每股目標價相應下降，總報酬分欄保留股息，無重複加回 |
| 借款／償債 | 現金與負債同時變動，借款本身不憑空創造權益 |
| 回購與稀釋 | 現金及股數同時調整，不能只縮分母；缺回購價格則停止 |
| 拆股 | 每股數字按比例改變，總權益、情境差距與總報酬不變 |
| 閏年、假日、不同季末 | 目標日期規則固定；評估市場價格日期另記 |
| 缺值、WACC≤g、未來資料、負權益 | 明確拒絕正式發布，不補零、不產生看似正常卡片 |
| 新財報／同季更正／新價格 | 財報可形成新候選，更正維持人工核對；行情不重算假設 |
| 舊、新研究修訂 | 歸因合計可重現，政策與資料版本完整保存 |
| 截止日前歷史重現 | 以當時來源重算，未來價格另庫評估，不使用 AI 後見知識 |

驗收依序是公式獨立手算、上述回歸案例、NVDA 一份真實但尚未發布的候選、數字與瀏覽器一致、方法複核，才啟用正式卡片。策略績效或 Sharpe 調參不作此方法正確性的替代證據。
